# Установка ПРОМТЕХНОСФЕРА на сервер

Платформа ставится одним скриптом на сервер с Linux (рекомендуется Ubuntu 24.04).
Внутри — пять частей в контейнерах Docker:

- **приложение**;
- **база PostgreSQL** — снаружи недоступна;
- **Caddy** — сам получает и продлевает сертификат https;
- **планировщик** — выписки банков, курсы ЦБ, уведомления, мониторинг;
- **резервные копии** — раз в сутки, с пробным восстановлением.

Время установки — около 30 минут, большая часть уходит на ожидание.

## Что понадобится

1. **Сервер (VPS) в России.** Персональные данные сотрудников по 152-ФЗ должны храниться на территории РФ. Подойдут Timeweb Cloud, Selectel, REG.RU, Yandex Cloud и подобные.
   - Система: **Ubuntu 24.04**.
   - Не меньше **2 процессоров, 4 ГБ памяти, 40 ГБ диска**.
   - После оплаты вы получите IP-адрес сервера и пароль пользователя `root` (или ключ SSH).
2. **Адрес (домен)** для входа, например `fin.promtehnosfera.ru`. Это поддомен сайта компании или новый домен (около 200 ₽ в год).
3. **Файл резервной копии** с этого компьютера — если переносите данные.

## Шаг 1. Направьте домен на сервер

В панели регистратора домена добавьте запись:

| Тип | Имя | Значение |
|-----|-----|----------|
| A   | `fin` (или `@` для самого домена) | IP-адрес сервера |

Запись начинает действовать через несколько минут, иногда через несколько часов. Без неё сертификат https не выдадут.

## Шаг 2. Подключитесь к серверу и установите Docker

На компьютере с Windows откройте PowerShell и подключитесь (вместо `IP` — адрес сервера):

```bash
ssh root@IP
```

Дальше все команды выполняются на сервере. Установите Docker официальным скриптом:

```bash
curl -fsSL https://get.docker.com | sh
```

Если на сервере включён брандмауэр `ufw`, откройте вход по SSH и для сайта:

```bash
ufw allow 22,80,443/tcp && ufw allow 443/udp
```

## Шаг 3. Скачайте программу

```bash
git clone https://github.com/daimusya/FinPTS.git /opt/promtehnosfera
cd /opt/promtehnosfera
```

## Шаг 4. Подготовьте данные для переноса (если переносите)

**На этом компьютере**, в папке программы:

1. Сделайте свежую копию:
   ```bash
   npm run db:backup
   ```
   В папке `backups` появится файл вида `promtehnosfera_2026-10-23_120000.dump`.
2. Скопируйте его на сервер (в PowerShell, вместо `ИМЯ` и `IP` — свои значения):
   ```bash
   scp backups\ИМЯ.dump root@IP:/opt/promtehnosfera/
   ```
3. Откройте файл `.env` в папке программы и найдите строку `AUTH_SECRET=...`. Её значение понадобится установщику. Это ключ, которым зашифрованы ключи интеграций (DaData, банки, почта, Telegram) и вход с кодом. Никуда его не пересылайте: вставите сами, когда установщик попросит.

## Шаг 5. Установка

На сервере, в папке `/opt/promtehnosfera`:

- с переносом данных:
  ```bash
  bash deploy/install.sh --restore ИМЯ.dump
  ```
- или с пустой базой:
  ```bash
  bash deploy/install.sh
  ```

Установщик спросит:

- **Адрес (домен)**, например `fin.promtehnosfera.ru`.
- **Почту администратора** — при переносе укажите свою почту для входа.
- **AUTH_SECRET прежнего компьютера** (только при переносе). Вставьте значение из шага 4: правая кнопка мыши в окне PowerShell, на экране оно не отображается.

Дальше установщик всё сделает сам:

1. Создаст надёжные пароли в файле `.env` на сервере.
2. Соберёт программу (5–10 минут).
3. Загрузит данные и перешифрует ключи.
4. Обновит структуру базы и запустит платформу.
5. Проверит адрес по https.

Если база новая, установщик напечатает **временный пароль** администратора. При первом входе система попросит его сменить.

## Шаг 6. После установки

1. Откройте `https://ваш-домен` и войдите.
2. Подключите себе **вход с кодом**: ссылка «вход с кодом» вверху.
3. В «Администрирование → Пользователи» выберите **«обязателен для всех»** (или «для администраторов»).
4. Заведите учётные записи тестировщикам:
   - роль давайте по задаче человека;
   - ограничьте видимость нужными организациями;
   - полный доступ администратора не давайте.
5. Если ключи интеграций не перенеслись (AUTH_SECRET пропущен), введите их заново в разделах «Интеграции» и «Каналы уведомлений».

**Важно: после переезда работайте только на сервере.** На этом компьютере:

- остановите платформу;
- в «Планировщике заданий» Windows отключите задачи `PROMTEHNOSFERA backup` и `PROMTEHNOSFERA bank statements`.

Иначе данные начнут расходиться по двум базам, а выписки будут загружаться дважды.

## Резервные копии

Копия делается раз в сутки в папку `/opt/promtehnosfera/backups`. Хранятся последние 14. Перед каждой копией выполняется пробное восстановление.

Периодически забирайте копии и файл `.env` с сервера в другое место. Без `.env` не прочитать зашифрованные ключи. В PowerShell на своём компьютере:

```bash
scp -r root@IP:/opt/promtehnosfera/backups .\копии-сервера\
```

Восстановить данные из копии вместо текущих (текущие сначала сохранятся отдельной копией):

```bash
bash deploy/restore.sh backups/ИМЯ.dump
```

## Обновление до новой версии

```bash
cd /opt/promtehnosfera && bash deploy/update.sh
```

Скрипт сделает копию, скачает новую версию, обновит структуру базы и перезапустит платформу. Данные и настройки сохраняются.

## Аварийный доступ и полезные команды

Все команды выполняются в папке `/opt/promtehnosfera`.

| Что нужно | Команда |
|-----------|---------|
| Забыт пароль (временный пароль напечатается на экране) | `docker compose run --rm tools npm run reset-password -- почта` |
| Потерян телефон для входа с кодом | `docker compose run --rm tools npm run reset-2fa -- почта` |
| Что запущено | `docker compose ps` |
| Журнал приложения | `docker compose logs -f app` |
| Журнал https (сертификат) | `docker compose logs caddy` |
| Перезапустить всё | `docker compose restart` |
| Состояние | страница «Администрирование → Мониторинг» |

## Если что-то не так

- **Сайт не открывается по https.** Проверьте, что запись A домена указывает на IP сервера и порты 80 и 443 открыты. Посмотрите журнал: `docker compose logs caddy`.
- **«Ключи не перешифрованы».** Значение AUTH_SECRET не совпало с тем, что в `.env` прежнего компьютера. Ключи интеграций введите заново. Вход с кодом у пользователей сбросьте командой `reset-2fa`.
- **Установка на Windows вместо Linux.** Возможна с Docker Desktop через Git Bash теми же командами. Но для сервера, который всегда включён и доступен из интернета, проще и надёжнее Linux.
